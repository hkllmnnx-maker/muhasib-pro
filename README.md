# محاسب برو — منصة تعلّم المحاسبة المالية

منصة تعليمية عربية احترافية متخصصة في تعليم **المحاسبة المالية من الصفر إلى الاحتراف**، بمحتوى غزير وأمثلة عملية محلولة وقيود محاسبية وأدوات حاسبية تفاعلية واختبارات ذاتية.

## نظرة عامة على المشروع
- **الاسم**: محاسب برو (MuhasibPro)
- **الهدف**: بناء مرجع تعليمي عربي متكامل يأخذ المتعلّم من أساسيات المحاسبة حتى المستوى الاحترافي (CMA/المحاسبة الإدارية).
- **اللغة والاتجاه**: العربية بالكامل، تخطيط RTL.
- **المميزات الرئيسية**:
  - 9 دورات متدرّجة (مبتدئ → متوسط → متقدم → احترافي) بأكثر من 60 درسًا.
  - محتوى تفاعلي: قيود محاسبية، معادلات، جداول، أمثلة محلولة، صناديق تنبيه.
  - 34 اختبارًا ذاتيًا مع شرح للإجابات.
  - قاموس محاسبي بأكثر من 200 مصطلح في 17 تصنيفًا.
  - مدونة تعليمية بـ 12 مقالة متخصصة.
  - أدوات حاسبية للمحاسب اليمني: المعادلة المحاسبية، الإهلاك بالقسط الثابت، الربحية، نقطة التعادل، هامش المساهمة، النسب المالية (السيولة والربحية والرافعة)، حاسبة ضريبة مبيعات تعليمية، حاسبة كشف رواتب تعليمية، وتحويل ميزان مراجعة مبسّط إلى قائمة دخل.
  - تتبّع التقدّم عبر LocalStorage + وضع ليلي/نهاري.

## معمارية البيانات
- **نماذج البيانات**: `Course`, `Module`, `Lesson`, `ContentBlock`, `Quiz`, `QuizQuestion`, `GlossaryTerm`, `Article` (انظر `src/data/types.ts`).
- **التخزين**: بيانات ثابتة (TypeScript) مُجمّعة وقت البناء؛ تقدّم المستخدم والثيم في **LocalStorage** بالمتصفح.
- **تدفّق البيانات**: ملفات البيانات → دوال مساعدة في `src/data/index.ts` → صفحات SSR (Hono/JSX) → HTML.

## دليل المستخدم
1. ابدأ من **الصفحة الرئيسية** أو **مسار التعلّم** لاختيار نقطة البداية المناسبة.
2. ادخل إحدى **الدورات** وابدأ بدروسها بالترتيب.
3. اقرأ الدرس، ثم اضغط **«إكمال الدرس»** لتسجيل تقدّمك (يُحفظ محليًا).
4. اختبر فهمك عبر **الاختبارات** المرتبطة بكل قسم.
5. استخدم **الأدوات الحاسبية** لتطبيق ما تعلّمته عمليًا.
6. ارجع إلى **القاموس** لفهم المصطلحات و**المدونة** للمقالات المتعمّقة.

## الأدوات الحاسبية في صفحة `/tools`
الأدوات تعمل لحظيًا أثناء الكتابة، وتتحقق من المدخلات وتمنع ظهور نتائج غير صالحة (NaN) عبر قسمة آمنة وقيم افتراضية:

| الأداة | المدخلات | المخرجات |
| --- | --- | --- |
| المعادلة المحاسبية | الأصول، الالتزامات | حقوق الملكية المحسوبة |
| الإهلاك (القسط الثابت) | التكلفة، القيمة التخريدية، العمر الإنتاجي | الإهلاك السنوي/الشهري ومعدّل الإهلاك (مع تحقق: العمر > 0 والتخريدية ≤ التكلفة) |
| الربحية | الإيرادات، تكلفة البضاعة، المصروفات | الربح الإجمالي/الصافي والهوامش |
| نقطة التعادل | التكاليف الثابتة، سعر البيع، التكلفة المتغيرة | هامش المساهمة، وحدات/مبيعات التعادل (تحقق: سعر البيع > التكلفة المتغيرة) |
| هامش المساهمة | سعر البيع، التكلفة المتغيرة، عدد الوحدات | هامش الوحدة، الإجمالي، النسبة |
| النسب المالية | أصول/التزامات متداولة، مخزون، نقدية، ديون، حقوق ملكية، صافي ربح، إجمالي أصول | نسبة التداول، السريعة، النقدية، الدين/حقوق الملكية، ROA، ROE |
| ضريبة المبيعات (تعليمية) | المبلغ، النسبة (يدوية، افتراضي 5%)، طريقة الحساب (شامل/غير شامل) | الصافي، الضريبة، الإجمالي |
| كشف الرواتب (تعليمي) | الأساسي، البدلات، نسبة تأمينات/ضريبة (يدوية)، خصومات أخرى | الإجمالي، التأمينات، الضريبة، إجمالي الخصومات، الصافي |
| ميزان مراجعة ← قائمة دخل | المبيعات، المردودات، تكلفة البضاعة، مصروفات إدارية/بيعية، إيرادات أخرى، مصروفات تمويلية | قائمة دخل مبسّطة: صافي المبيعات، مجمل الربح، الربح التشغيلي، صافي الربح/الخسارة |

### المصادر الرسمية اليمنية للأدوات الضريبية
> ⚠️ **تنبيه**: الأدوات الضريبية (ضريبة المبيعات وكشف الرواتب) **تعليمية فقط** وليست إقرارًا ضريبيًا رسميًا. تترك النسبة **يدوية** للمستخدم، ويجب الرجوع إلى **مصلحة الضرائب اليمنية** أو مستشار مختص للتحقق من النسب والقواعد السارية.

1. **النسبة العامة لضريبة المبيعات = 5%** — القانون رقم (19) لسنة 2001م بشأن الضريبة العامة على المبيعات.
   - مصلحة الضرائب اليمنية (اللائحة التنفيذية): https://taxauthority-ye.tax/sales-tax-laws-executive-regulations/
   - تأكيد النسبة العامة (5%): ويكيبيديا — الضرائب في اليمن: https://ar.wikipedia.org/wiki/الضرائب_في_اليمن
2. **شرائح ضريبة المرتبات والأجور** — قانون ضرائب الدخل رقم (17) لسنة 2010م (المادة 62): حد إعفاء سنوي 840,000 ريال (0%)، ثم 120,000 التالية (10%)، ثم 120,000 التالية (15%)، ثم 20% على ما زاد عن 1,080,000 ريال سنويًا.
   - النص الرسمي (مصلحة الضرائب اليمنية): https://taxauthority-ye.tax/wp-content/uploads/2024/05/قانون-رقم-17-لسنة-2010-بشأن-ضرائب-الدخل.pdf

> ملاحظة منهجية: التزامًا بالشرط، لم تُثبَّت أي نسبة ضريبية في كود الحساب نفسه؛ تُترك النسبة قابلة للتعديل من المستخدم، وتُعرض النسبة الموثّقة (5%) كقيمة افتراضية اختيارية فقط مع توثيق مصدرها.
