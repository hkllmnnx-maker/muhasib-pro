# محاسب برو — منصة تعلّم المحاسبة المالية

منصة تعليمية عربية احترافية متخصصة في تعليم **المحاسبة المالية من الصفر إلى الاحتراف**، بمحتوى غزير وأمثلة عملية محلولة وقيود محاسبية وأدوات حاسبية تفاعلية واختبارات ذاتية.

## نظرة عامة على المشروع
- **الاسم**: محاسب برو (MuhasibPro)
- **الهدف**: بناء مرجع تعليمي عربي متكامل يأخذ المتعلّم من أساسيات المحاسبة حتى المستوى الاحترافي (CMA/المحاسبة الإدارية).
- **اللغة والاتجاه**: العربية بالكامل، تخطيط RTL.
- **المميزات الرئيسية**:
  - 4 دورات متدرّجة (مبتدئ → متوسط → متقدم → احترافي) بأكثر من 29 درسًا.
  - محتوى تفاعلي: قيود محاسبية، معادلات، جداول، أمثلة محلولة، صناديق تنبيه.
  - 14 اختبارًا ذاتيًا مع شرح للإجابات.
  - قاموس محاسبي بأكثر من 45 مصطلحًا.
  - مدونة تعليمية بمقالات متخصصة.
  - أدوات حاسبية: المعادلة المحاسبية، الإهلاك، الربحية، نقطة التعادل، النسب المالية.
  - تتبّع التقدّم عبر LocalStorage + وضع ليلي/نهاري.

## مسارات الوصول الوظيفية (URIs)
| المسار | الوصف |
| --- | --- |
| `/` | الصفحة الرئيسية |
| `/courses` | قائمة جميع الدورات |
| `/course/:slug` | تفاصيل دورة (`fundamentals`, `financial-statements`, `advanced-accounting`, `professional-cma`) |
| `/course/:slug/:lessonSlug` | صفحة درس تفاعلية |
| `/quiz/:id` | صفحة اختبار |
| `/tools` | الأدوات الحاسبية |
| `/roadmap` | مسار التعلّم المتدرّج |
| `/glossary` | القاموس المحاسبي |
| `/blog` | قائمة المقالات |
| `/blog/:slug` | مقال مفرد |
| `/about` | عن المنصة |

## معمارية البيانات
- **نماذج البيانات**: `Course`, `Module`, `Lesson`, `ContentBlock`, `Quiz`, `QuizQuestion`, `GlossaryTerm`, `Article` (انظر `src/data/types.ts`).
- **التخزين**: بيانات ثابتة (TypeScript) مُجمّعة وقت البناء؛ تقدّم المستخدم والثيم في **LocalStorage** بالمتصفح.
- **تدفّق البيانات**: ملفات البيانات → دوال مساعدة في `src/data/index.ts` → صفحات SSR (Hono/JSX) → HTML.

```

│   ├── index.tsx                # نقطة الدخول وتعريف المسارات

│   └── app.js                   # منطق الواجهة الأمامية

├── wrangler.jsonc               # إعداد Cloudflare Pages

```

## دليل المستخدم
1. ابدأ من **الصفحة الرئيسية** أو **مسار التعلّم** لاختيار نقطة البداية المناسبة.
2. ادخل إحدى **الدورات** وابدأ بدروسها بالترتيب.
3. اقرأ الدرس، ثم اضغط **«إكمال الدرس»** لتسجيل تقدّمك (يُحفظ محليًا).
4. اختبر فهمك عبر **الاختبارات** المرتبطة بكل قسم.
5. استخدم **الأدوات الحاسبية** لتطبيق ما تعلّمته عمليًا.
6. ارجع إلى **القاموس** لفهم المصطلحات و**المدونة** للمقالات المتعمّقة.
