# تقرير المصادر — توسعة دورة المراجعة والتدقيق (البيئة اليمنية)

**الفرع:** `agent-07-yemen-auditing`
**الملف المُوسَّع:** `src/data/course-auditing.ts`

هذا التقرير يوثّق المصادر المهنية والرسمية التي استُند إليها عند توسعة محتوى دورة
«مراجعة الحسابات والتدقيق». المحتوى **تعليمي** ولا يُعدّ استشارة مهنية أو قانونية ملزمة.

---

## 1) المصادر المهنية الدولية (مفاهيم المراجعة)

| المرجع | الموضوع في الدورة | المصدر |
|--------|--------------------|--------|
| **ISA 300** — تخطيط مراجعة القوائم المالية | درس برامج المراجعة وتخطيطها | مجلس المعايير الدولية للمراجعة والتأكيد (IAASB) — iaasb.org |
| **ISA 315** — تحديد وتقدير مخاطر التحريف الجوهري وفهم الرقابة الداخلية | الرقابة الداخلية وتقدير المخاطر | IAASB — iaasb.org |
| **ISA 320 / ISA 450** — الأهمية النسبية وتقييم التحريفات | الأهمية النسبية | IAASB — iaasb.org (مشروع/إصدار ISA 320 و450) |
| **ISA 500** — أدلة المراجعة (الكفاية والملاءمة) | أدلة الإثبات وتأكيدات الإدارة | IAASB / IFAC — iaasb.org, ifac.org |
| **ISA 501** — أدلة المراجعة: اعتبارات محددة لبنود مختارة (حضور جرد المخزون) | مراجعة المخزون | IAASB / IFAC |
| **ISA 700 / 705 / 706 / 701** — تكوين الرأي والتعديلات عليه وفقرات لفت الانتباه والأمور الرئيسية | تقرير المراجع وأنواع الرأي | IAASB / IFAC — ifac.org (ISA 705 Revised) |
| نموذج مخاطر المراجعة (Inherent × Control × Detection) | مخاطر المراجعة | ACCA Technical Article — accaglobal.com (Audit Risk, F8/AA) |
| إطار **COSO** للرقابة الداخلية | مكونات الرقابة الداخلية | إطار COSO (مرجع عالمي شائع) |

> ملاحظة: أرقام معايير ISA مرجعية عامة معترف بها دولياً وصادرة عن IAASB ضمن مظلة IFAC.

## 4) إخلاء مسؤولية

- جميع الأسماء والأرقام في الحالات العملية **افتراضية بالكامل** لأغراض التدريب فقط.
- المحتوى تعليمي ولا يُعد استشارة مهنية أو قانونية ملزمة.
- أرقام القوانين والمواد مذكورة استناداً إلى المصادر الرسمية المتاحة وقت الإعداد؛
  ويجب التحقق من آخر النصوص النافذة لدى الجهات الرسمية قبل أي تطبيق عملي.
